   - Adequate spacing between elements

================================================================================
                        RESPONSIVE BREAKPOINTS
================================================================================

@media (max-width: 1024px)
  - Sidebar and main content stack vertically
  - Layout becomes single column
  - Images and boxes scale down

@media (max-width: 768px)
  - Hamburger menu appears
  - Navigation moves to mobile menu
  - Sidebar becomes overlay
  - Tables convert to cards
  - Font sizes reduce slightly
  - Padding/margin optimized

@media (max-width: 480px)
  - Ultra-optimized spacing
  - Larger touch targets
  - No horizontal scrolling
  - Single-column layout
  - Smallest possible margins
  - Maximum readability
